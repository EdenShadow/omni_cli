# Omni CLI 0.3.21

完整版同步万物 AI 1.2.513 已发布的设备执行核心，随附万物同步助手 1.22.3。

- 远程任务通过当前任务范围进行安全检查。发现可疑请求时，设备只提交原因分类。上报遇到网络故障会保存待发送记录，恢复连接后补报。
- 常驻进程使用已登录账号恢复原设备绑定。并发恢复共用请求，登录失效后停止重复恢复，临时故障按退避时间重试。恢复请求附带 CLI 版本与账号标识，方便管理员核对失败来源。
- 运行中的任务可以同步普通及加密会话的文件卡片。文件归属具体来源指令，远端查看时按需取文件。
- 团队加入申请返回待审批状态和申请编号。登录失败给出统一提示。

现有安装可在原运行账号下更新，停止旧进程后重新运行 `omni start`。独立 Omni Mini 通道保持 0.3.14。
