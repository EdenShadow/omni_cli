# Omni CLI 0.3.20

CLI 执行端同步当前万物 AI 执行核心与万物同步助手 1.22.1；万物画布保持 1.13.0。

- AI 可以把明确指定的附件直接交付到当前已导入的会话，无需发送到团队公屏。文件在设备端加密，保留来源会话、项目及本地目录访问权限；明确要求公屏时仍可使用原有公屏命令，失败不自动转发。
- 附件交付重试沿用稳定请求标识，可恢复已完成的上传；拒绝应用私有数据、凭据文件和不在授权目录内的文件。
- 旧加密消息根据原始提交判定可见性，避免运行时注入说明误伤普通消息；保留用户显式选择和原有隐藏状态。
- 官方发布应用沿用项目发布通道同步，不再按普通 GitHub 技能进行来源自动更新；普通 GitHub 技能仍可检查更新。

新会话附件功能需要万物服务端和查看端 1.2.488 或更新版本。升级保留原有账号、设备绑定、NAS、模型与会话配置，安装后重启 `omni start`。本包使用已安装的 Codex、Claude Code 或 DeepSeek Harness，不附带快赢 CLI 或内置 AI Runtime。独立 Omni Mini 下载保持 0.3.14，无需跟随升级。

验证：133 个模块与 CLI 导入图检查通过；带本地服务器联调的 79 项测试全部通过，无跳过。新增测试覆盖技能命令到 CLI 桥的附件交付、重复请求、访问撤销、私有目录保护、旧消息可见性及官方应用更新来源。测试使用临时账号和模拟 Runtime，不调用付费模型、不向真实公屏发送消息。
