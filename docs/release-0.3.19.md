# Omni CLI 0.3.19

同步万物 AI 1.2.478 的技能自定义互动协议。CLI 设备上的 AI 任务可请求会话内或全局互动页面；多步表单、小游戏和照片选择由 Mac/Web 客户端展示。文本和原始附件回到来源会话，沿用模型与强度；加密会话保持页面和回答加密。

随包提供万物同步助手 1.21.0 与万物画布 1.13.0。自定义页面控制关闭、取消、提交和体感授权。生成的画布可指定初始分享模式，并通过名称与封面卡片打开。

需要万物服务端与交互客户端 1.2.478 或更新版本。现有账号、NAS、模型和设备绑定保留；安装后重启常驻进程。Omni Mini 不执行 AI 会话，无需更新。本包不携带快赢 CLI 或 AI Runtime。

验证使用隔离服务器和本地模拟 Runtime，不产生付费模型调用。CLI 测试与 132 模块导入图检查通过。
