# Omni CLI / Mini 0.3.3

- 新增独立 Omni Mini：账号登录、项目列表、可 @会话与备注、公屏加密收发和远端结果等待。独立包零第三方依赖，不包含本地 AI 执行桥、模型 SDK 或技能库；需要 Node.js 24+。

安装与下载见 [Mini 文档](../mini.md)。完整 CLI 使用 `npm install -g github:EdenShadow/omni_cli#v0.3.3`。当前没有发布 npm registry 包。
