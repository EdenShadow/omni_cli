# DIY 美术自由度

默认场景保留像素风。用户主动 DIY、指定参考图或描述风格时，用户的美术方向优先；不要把像素、方格地砖、棕色木框、同一套沙发绿植强加给所有作品。这里的示例是灵感，不是可选风格清单，也不要求用户先选套餐。

先从提示词确定一个完整方向，再落到空间里：墙面与地面形状、主要材质、家具轮廓、明暗与色彩、一个突出主题的原创视觉元素。改变风格至少应改变实际表面与关键家具的绘制，不能只改名称和 palette。可以用圆润插画、纸艺、线描、未来实验室、自然庭院、奇幻空间，也可以组合出不在示例中的方向；轻微顶面、斜面和体积感都可以，只要实际占地与点击、坐点仍对应。用户只要求局部 DIY 时只改对应部分。

`renderMode: "pixel-grid"` 是兼容的布局和碰撞数据格式，不代表所有图形必须有像素锯齿。格子用于尺寸与导航；绘画可使用任意安全 SVG 曲线、椭圆、路径、描边、透明叠层与局部坐标。无需把图案轮廓吸附到格子。现有无 appearance 的存档仍按像素风渲染。

## 独立绘制墙面、地面

office.json 支持可选字段：

```json
{
  "appearance": {
    "rendering": "smooth",
    "floorSvg": "<svg viewBox='0 0 1000 700'><rect width='1000' height='700' fill='#edf2e9'/><path d='M0 400 Q400 180 1000 450 L1000 700 H0Z' fill='#d7e4d6'/></svg>",
    "wallSvg": "<svg viewBox='0 0 1600 320'><rect width='1600' height='320' fill='#e4ede9'/><path d='M0 80 Q800 180 1600 40' fill='none' stroke='#b5ccc0' stroke-width='12'/></svg>"
  }
}
```

`rendering` 只控制画线方式：pixel 保持像素锐边，smooth 使用平滑曲线和圆润看板边框，不是主题枚举。floorSvg 只覆盖看板下方地面，wallSvg 覆盖顶部墙面；都被裁切在各自区域，按照 viewBox 拉伸铺满。它们只有装饰，不承担碰撞；需要阻挡的墙、能坐的椅子、可点击的道具仍必须使用独立模块。地面可用拼接、波纹、地毯岛、石板、小径、几何图案等原创画法；不要一律画方格。大背景按横纵尺寸设计，重要图案不依靠拉伸维持外形。缺少某一层时该层沿用默认外观。

每层完整 SVG 不超过 160 KB，沿用安全内联形状规范：svg/g/path/rect/circle/ellipse/line/polyline/polygon/defs/clipPath/title/desc；直接写 fill/stroke 等属性，不用脚本、style、外链、图片或主动内容。不要把成员、真实电脑、看板正文或操作按钮画死在装饰层。顶部 wallSvg 可用安全 text/tspan 绘制春联等装饰文字，floorSvg 仍不包含文字；面板内部底纹与配色见 [看板外观](board-appearance.md)。

## 家具不必长得一样

已有 sofa/table/plant/bookshelf 等模块可直接增加 `svg`，宿主优先绘制原创 SVG，保留 kind、id、尺寸、坐点、碰撞与摆放逻辑。例如 sofa 仍叫 sofa，但可画成云朵沙发、纸艺长凳或流线型座椅。新增没有对应语义的东西用 kind:custom。明确要求门牌/名牌时使用独立 custom 道具的安全 text/tspan，不自动给每间房加浮动标题。SVG viewBox 按模块宽高比例设计，透明背景、在自身范围内；可用原有 animations 受控动画，默认静态。

用户要求重新 DIY 时，可继续重绘没有 assetId 的内置家具 svg，同时保留其身份与互动元数据，不能把它退回默认造型。已经独立收藏或拥有 assetId 的道具仍保留原艺术文件与行为；需要编辑这些资产时走对应道具编辑流程。设备和成员仍由真实身份动态绘制，整体场景 DIY 不应把它们烘焙进背景。

## 保留必要约束

新场景默认以 50×32 格起步，比例与密度按 [空间设计](spatial-design.md) 决定；用户明确要求改变时不把默认格数当作固定限制。上方三块看板正面可读，实际工位、座位、门和通路可达。已有的自定义道具身份、canvasId、行为和用户数据必须保留。用校验器检查，再看正常及窄屏预览；验收风格时比较实际画面，不以换名称、换配色或列举创意代替实现。

用户要求调整比例时，允许重新设计模块占地、密度和视觉大小，不把模板尺寸当成审美限制。先用宿主 100% 视图看整体，再缩放看局部，检查人物与工位、沙发与茶几、道具与通路是否协调；减少拥挤也要避免把所有物件缩得太小、散在无意义的大空地里。大型主题装置可以有意突出，其余陈设围绕工作区或休闲区成组。至少对比正常桌面和窄屏截图，根据截图调整一轮；不要只看独立 SVG 的大图。
