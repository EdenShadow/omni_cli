## 提取与发布技能

下列命令省略 `node /absolute/wanwu-skills-sync/scripts/sync.mjs` 前缀，沿用 SKILL.md 中已确定的范围参数。

1. `context --include skills` 返回当前 session.id、deviceId 和项目技能版本。指定其他设备/会话时加 `--include devices,sessions`，按返回 ID 匹配；只选择用户要求的那个技能。
2. `catalog --device DEVICE_ID --session SESSION_ID` 列出标准技能目录和所选会话内的 `.codex/skills`、`.claude/skills`、`.agents/skills`、`skills`、`bundled-skills` 以及工作目录本身的 SKILL.md；`--session` 可省略。
3. 预览前检查技能图标，按下方“专属图标”准备。`preview --device DEVICE_ID --candidate CANDIDATE_ID --version VERSION` 提取并预览。新技能默认 1.0.0，已有技能高于最高已发布版本；用户指定则采用指定版本。核对 SKILL.md、图标、文件列表与校验值。脚本、参考文件一并打包，排除安装回执；符号链接、隐藏配置、密钥及超限内容会拒绝。
4. 用户已要求同步时，直接 `publish --request PREVIEW_REQUEST_ID`。只有 `published` 才表示成功。服务端上传 COS、回读校验并广播。已有技能只有作者或项目发起者能发新版；不换身份绕过权限。固定旧版本的项目不会自动切到新版，应如实说明。
5. 报告项目、技能、版本和结果后**结束本轮**。设备等活跃会话结束才更新，不要在本会话内无限等待自己恢复就绪。其他设备各自更新后恢复任务/定时队列。

来源离线则提示上线；过期候选重新 catalog；版本冲突刷新 context 后重新 preview。`pending` 不是完成，用 `result --request REQUEST_ID` 查询。若技能只存在于文字，先整理为所选工作目录中独立、含 SKILL.md 的技能目录，不把聊天总结冒充已有文件。

### 大资源包

单个技能全部文件合计最多 1000 MB（1000 × 1024 × 1024 字节），最多 512 个文件。Windows 与 Mac 的 1.2.340 及以后客户端支持同一分块协议；来源和接收设备均需更新。`context.capabilities.skillPackages` 返回服务端能力。资源由客户端按 4 MB 分块上传与下载、逐块及整文件校验，重试复用已完成的分块；不要把大文件手动转成一个 JSON 请求。元信息文件最多 1 MB。

大包预览可能返回 `pending`：保留 requestId，用 `result --request REQUEST_ID` 继续查看，不重复新建预览。只有 `ready` 后才发布。网络失败时可重试相同来源与版本；发布成功不代表离线设备已经完成下载。

### 凭据依赖声明

注册、创建或发布自己维护的技能时，先按 [钥匙库](credentials.md) 在根目录填写 `wanwu.credentials.json`，由技能自己声明所需的 API Key、账号密码、用户 ID 以及配置入口；没有依赖则声明空数组。预览时核对技能归属和字段定义。实际值在发布后的钥匙面板填写，不打进技能包。同步后使用该技能时，应按声明读取当前团队已有凭据，缺失才进入配置或注册流程。只允许提取的第三方来源不擅自改写，报告其尚未声明依赖。

### 专属图标

每个新技能优先提供贴合实际用途的独立插画，不能把自动公文包、工具箱或同一颗星星当作设计完成。先读名称、简介和主要能力，再选具体主体，例如 PPT 用幻灯片配图片、视频用场记板、查账用票据配计算器。同类技能也应通过主体组合和构图区分，不只给同一模板换颜色。

已有有效自定义图标就保留。自己正在创建或可编辑的发布副本缺图标时，补充 `assets/skill-icon.svg`，并用 `metadata.icon: assets/skill-icon.svg` 或 `agents/openai.yaml` 的 `interface.icon_large` 引用。SVG 使用 128×128 viewBox、圆角底色、清晰的实心主体、3–5 种协调颜色和简单明暗；用路径、矩形、圆等自包含图形，不加脚本、外链、文字、嵌入图片、滤镜和动画。在 40px、76px 下检查可读性。不要为了补图标安装工具、复制凭据或自动调用付费生图服务。

导入的原始文件、其他设备上的技能或当前只允许提取的来源，不为补图标擅自改写；使用宿主按名称和用途生成的展示图标。无法识别用途时宿主提供稳定、独立的几何图案兜底，不能声称这是专门设计的语义插画。发布后才发现仍是通用默认图标，应先修正可编辑的发布副本，再预览并发布新版本。

### 已有安装的保护

同步发布的是技能文件，不是重新安装 CLI 的指令。不要为了分享快赢 CLI 或其他技能而运行安装脚本、包管理器、升级命令，或复制账号配置。来源设备和其他设备都由宿主核验已有技能：名称与文件内容一致时复用原目录；同名内容不同时保留本地版本并报告冲突，不自动覆盖、不改名再装一份。项目补充的展示图标不需要写回原技能。备份目录不作为安装候选。

实际使用技能需要 CLI 时，先用只读方式检查 PATH、技能文档指定的位置以及版本/能力；已有兼容 CLI 就复用。仅当确实缺少任务所需依赖且任务已授权安装时才安装；不能仅因同步技能而重装、升级、重置配置或替换密钥。不要声称“所有设备已安装”：发布成功和各设备核验/同步完成是不同状态。


### 项目界面扩展

用户要求技能附带项目按钮、表单或修改指定 UI 元素时，按 [项目界面扩展](ui-extensions.md) 在技能根目录编写 `wanwu.ui.json`。预览时核对 `ui` 声明；扩展随项目选用的技能版本生效，成员共享，删除技能或切换项目时自动撤销。普通技能不必添加扩展。
