# 情绪工作与独立完成状态

生成新角色，或编辑“疯狂/抓狂/emo 工作”“工作表情包”“搞定了”等动作时读取。用户可追加、替换、删除动作，不能只能创建、不能只改标签。

## 两种不同语义

- `working` 表示任务仍在执行。默认至少五个工作变体：两个职业行为，加疯狂赶工、抓狂返工、emo 工作。已有池按请求保留或调整，用户可指定其他组合；不要求所有角色用同一套动作。
- `done` 表示任务已经完成，是独立公开状态。只由用户按钮或宿主任务完成事件显式触发；不要加入 `workVariants` 或待机池。
- `done` 的 clip 用 `loop: false`，每段播完后由独立动画时钟随机接下一段，持续庆祝直到显式切换。不要沿用“所有有限 clip 结束回 idle”的逻辑，只有待机小动作可以自动回 idle。减少动态时显示完成的最后一帧。
- 编辑旧五状态包时为该角色补 done、UI 与适配器；通用播放器继续接受旧包。旧角色未升级时调用 done 应报不支持且保留原状态，不假装完成。

## 表情与肢体一起设计

| 情绪 | 五官线索 | 动作节奏 | 职业联系 |
|---|---|---|---|
| 疯狂 | 螺旋/瞪大眼、张嘴咬牙、清楚的汗滴 | 大幅交替挥臂连击，明显倾身与换重心；蓄力、爆发、短停，配饰滞后 | 连敲键盘、密集记笔记、疯狂画线 |
| 抓狂 | 挤眼、扭眉、张嘴抱怨、清楚的怒气线 | 后仰蓄力→双手举起/抱头/跺脚→大摆头→扑回工作；不等同于疯狂加速 | 抱怨返工、划掉重写、反复核对 |
| emo | 半垂眼、嘴角下弯、阴影线/泪滴 | 明显塌肩垂头、手臂垂落→费力抬手敲一次/写一笔→再次泄气，中间有停顿 | 沮丧但仍在工作，不能变成睡觉或挂机 |
| 搞定了 | 大笑、弯眼、兴奋的身体预备 | 喷彩带连跳 / 撒花摇摆 / 大跳欢呼 → 开心收尾 | 完成事件才触发；在独立庆祝池随机选一种 |

这些是创作方向，不是要求每只角色照抄的五官模板。细长前辈、方块成员、小萌新要各有强度和习惯。保持母版轮廓、识别配饰、平涂画风与自然宽度；不靠压扁身体、全身高速抖动、闪屏或加文案冒充情绪。

## 默认大幅度与可读性

新建角色默认有动画片式的大表演，不等待用户额外要求“再夸张一点”。用户明确要求克制/淡定时才降低强度。

- **先定关键姿势，再补中间帧**：每段至少能截出起势、极限姿势、回到任务三张不同剪影。五官变化与身体同步，不能用同一个动作加速或改标签充数。
- **疯狂赶工**：一轮约 1.2–1.8 秒。约前 10–15% 蓄力，中段 2–3 次交替大挥臂/敲击，最后 20% 短暂停顿再继续。主执行手臂以约 55–90°的角度跨度起步，身体前倾/左右换重心约 12–20°；按真实关节调整，数字不是绝对姿势。持物手保持物品连接，执行手的接触点正确。不能只高频摇手腕。
- **抓狂返工**：一轮约 2.4–3.6 秒。举臂过肩、抱头或跺脚至少一种清晰大姿态，极限姿势停住 200–400ms，再大幅返回敲击/写画。与疯狂的连击节奏明显不同，不全程抖动。
- **emo 工作**：一轮约 3.2–4.8 秒。塌肩、垂头与手臂的剪影变化要大；长停后费力做一笔/敲一下再垂落。慢不等于只动 1–2px，也不能演成睡觉或停止工作。
- 角度量级均指起止的**跨度**，不是把不同角色设置成同一绝对关节角。大头、短手、长耳、手持画板分别调节；已有幅度很大的轨道不要机械倍乘。
- 允许手臂、头发、汗滴、速度线超出静态人物框，人物本体保持原尺寸，宿主不能裁切；特效服务肢体，不遮满脸。脚仍有接触/抬起/落地，根层位移携带整个身体与脚，不能把脚留在地面造成断腿。不得横向拉扁母版或用整人高频震动冒充疯狂。
- 分开的后脑/刘海/脸层须使用一致头部变换；肩、肘、手持物跟随父关节。大动作最远帧也必须没有断肢、掉脸、脱手、穿地。

### 小尺寸验收

在场景实际尺寸（约 124×137 世界单位）和 96px 高度各检查一次：不开动作标签，能从姿势辨认三种情绪；疯狂的主手端点移动应达到可见主体宽度约四分之一，而非几像素颤动。对比待机与工作关键帧，看剪影是否真的改变。连续观看两轮，检查蓄力与停顿，不只交一张静态图。

新创作或已逐帧验证的大幅工作包可写 `design.workPerformance: "authored-v1"`，让宿主直接播放作者轨道，不叠加旧包兼容增强。**只有完成上述视觉检查才标记**，不能只添加此字段交差；未标记的旧包可由播放器补强弱动作。修改其他状态时不要随意新增此标记。

## 分层与轨道

SVG 可在现有 `face` 下添加独立的 `data-expression` 组，通过根 `data-clip` 切换显示。例如 work-frantic、work-frustrated、work-emo；这些 id 是样例，可命名为角色专属 id，但必须同步选择器、manifest 与标签。保留眼镜、胡子和蝴蝶结等身份标识；需要隐藏普通眼/嘴时仅隐藏对应层，避免眨眼轨道覆盖情绪五官。

表情跟随 face；泪滴、怒气符号用少量平涂线条，别变成大面积贴纸遮脸。新增动态层必须有唯一 data-part、正确锚点和真实 clip 引用。切走工作时隐藏所有情绪残留，恢复该目标状态的正常表情。Canvas/骨骼实现使用对应绘制或节点机制，不能生搬 SVG 选择器。

轨道必须体现节奏差异，而不只是换脸或改 duration。手、笔尖与纸、键盘保持合理接触；画板/电脑不能挡住所有嘴部表演。裙摆和头饰跟随父层。循环首尾连续，结束工作、切角色、暂停和卸载都取消/暂停旧调度，不能被过期回调拉回工作。

## 编辑流程与验收

1. 读取现有包和工作池，按用户要求增删改具体表情与轨道；保留 id、接受的外形和无关动作。备份沿用项目机制。
2. 同步 `workVariants`、`workLabels`、clips、SVG 选择器以及动态预览；删除的变体不再有按钮或残留引用。done 只出现在公共状态列表，庆祝变体在独立 doneVariants 池。
3. 校验包并构建；浏览器逐个点选情绪，查看循环中间姿态，工作→done 等旧工作切换间隔过去仍保持完成；done→idle/左右走/犯困无残留。验证暂停、减少动态和手机布局。
4. 改公共播放器后回归已有角色与旧五状态包。校验器可兼容旧包少于五种工作变体；新建质量要求仍以本技能为准。

调用例子：
- `/office-character-studio 新建一个细长铅笔成员，工作会疯狂速写、抓狂擦掉重来、emo 写一笔停一下，另有独立搞定了状态。`
- `/edit-character 橘子妹妹 把抓狂改成举笔抗议再继续画，保留裙子和蝴蝶结，搞定了保持独立。`
- `/edit-character 香蕉叔叔 删掉疯狂工作，新增淡定喝茶后继续记笔记；保留其他动作。`

## 随机的大庆祝

新生成或升级的角色默认提供至少三种 `doneVariants` 与对应 `doneLabels`：喷彩带连跳、撒花摇摆、大跳欢呼。进入 done 后持续随机抽取，避免相邻重复；`playDone(id)` 可单独预览。各个庆祝均 `loop: false`，每轮结束继续抽取下一种，直到显式切换状态，不混入 workVariants/idleVariants。保留基础 done 作为旧包和减少动态回退。

- 用整个角色的根层做 2–3 次有起落的大跳，落地短停、第二跳可更高。脚、身体与手持作品共享腾空位移，不能只抬身体把脚留在地上；长角色按视口与重心调幅度。裙摆、叶子、领带作滞后摆动，不拉宽压扁身体。
- 彩带从两侧向上喷射，旋转下落淡出；撒花用可辨认的花瓣/小花轮廓。沿用角色平涂配色，别挡住整张脸。不同庆祝要在节奏、姿势和粒子类型上有区别，不能只改名称。
- 粒子放在独立场景层，不随角色身体跳动；所有轨道受同一播放器管理。默认不可见，只在 done 下显示，有限播放末帧 opacity=0；切状态、换角色、暂停、离屏与卸载的行为与角色一致。减少动态时不喷粒子、不跳，保持开心的静态完成姿态。
- 彩带不能越过展示区挤到按钮或被裁切，检查最高点、最低点、小尺寸和手机。预览的庆祝按钮从 characterready.detail.doneVariants 动态生成，只在 done 状态出现。
- 验证随机覆盖与相邻不重复、三种庆祝的中间帧、完成保持、重复点击可重播、切回工作/待机无残留、暂停恢复以及减少动态。单张静态截图不能证明跳跃时序。

编辑示例：`/edit-character 橘子妹妹 给搞定了增加喷彩带三连跳、撒花转裙舞和举画大欢呼，随机抽一种，保留服饰，工作池不变。`

## 宿主统一的工作特效

万物 AI 播放器在 `working` 时统一叠加烟雾、扳手、螺丝刀和螺丝钉。每次进入工作随机选择棉花烟、旋涡烟、细蒸汽、爆蓬烟之一，当前工作期间保持该样式连续播放，不因工作姿势随机轮换而重抽。退出工作立即清理；暂停、离屏与页面隐藏时暂停，减少动态显示静态标识。所有现有和新建角色以及工作分身都由宿主自动覆盖。

角色包继续设计自己的身体表演；不要把这套公共烟雾和工具再画入 SVG，也不要增加独立计时器或为此重新生成角色。缩略头像和独立动作预览不显示公共工作特效。特效层位于头顶与两侧，不跟随身体倾斜、不遮住脸、不阻挡点击。
