# 先融入项目，再成为角色

## 读取现场

应用会提供 `SCENE_CONTEXT.json`：当前项目配色、家具类别、实际人物画框、现有默认角色。不包含会话内容、账号资料或公告。`source` 含 unavailable 时是默认场景回退，不能说已读取用户自定义场景。仓库工作时也检查宿主 CSS 和母版文件，以真实尺寸为准。

当前默认项目是薄荷绿墙、奶油格子地板、木质设备桌、紫色沙发和绿色植物。角色继续采用深色手绘线条、平涂和自然曲线，环境的像素格子不要求角色也像素化。借用一两种环境颜色，让主体和地面保持对比；不用背景图填充角色。

## 设计不同的成员

先用一句话确定物品原型、剪影、性格和招牌动作。已有圆润橘子、细长香蕉、方形芽团；新成员应扩展轮廓，而非改色复刻。新增默认例子：

| 角色 | 剪影和识别物 | 动作动机 |
|---|---|---|
| 咖啡冲冲 | 横向杯身、开口把手、奶泡刘海、薄荷釉色 | 闻咖啡、整理奶泡、赶待办；快节奏手臂与滞后的奶泡 |
| 灵感灯灯 | 上宽下窄的灯泡、螺纹底座、紫围巾 | 歪头想点子、灵光闪现、画草图；离散亮线，不用发光滤镜 |
| 蘑菇慢慢 | 宽扁波浪菌盖、矮菌柄、斜挎口袋 | 听风、翻口袋、读小书；慢半拍的帽沿和悬空小脚 |

这是差异化的例子，不是要求以后都套用这三只。每个角色至少三个有身体结构依据的待机小习惯，工作里两个专属动作加疯狂/抓狂/emo；坐着也保留各自的习惯。不要用同一动作只换标签。

可运行母版见 `assets/default-cast/coffee-rush/`、`assets/default-cast/idea-bulb/`、`assets/default-cast/mushroom-mellow/`。按需读取其中一只的 JSON 和 SVG，借鉴部件定位、表情切换和有限粒子轨道；新建角色仍重新设计轮廓。用户要求编辑这三只时可以直接从对应母版开始。

## 宿主比例与接触点

- 当前地图画框约 124 × 137 世界像素，选择页约 160 × 175；顶部头像更小。画框不等于可见身体尺寸，新建按 [默认场景体量](body-proportions.md#默认场景体量) 留出适度空间；先检查脚底一致、剪影有差异、眼睛看得见。核对真实地图比例，不以放大的选择卡片作为尺寸依据。
- SVG 使用透明背景，地面阴影和分身颜色由宿主绘制。不带一张完整桌子、电脑、椅子或房间；小记事本、笔、手柄等个人道具可以属于角色。
- 站立脚底是移动锚点；坐姿另画弯腿和垂脚，以臀部接触点填写 `seating.hipAnchor`，不要仅把整个人下移。
- 外层静态组定位部件，内层 `data-part` 负责动画。父组带动附件，避免手离臂、帽离头；`transform-origin` 用该母版关节坐标。眨眼用短时间 offset，别把半个循环都用来闭眼。
- 工作表情按 clip 显示，切离工作立即复位；粒子放独立组，只在 done 可见。每个庆祝 clip `loop:false`，宿主完整播放后抽取下一个，不自行设 timeout 或 CSS infinite 动画。

## 接入默认阵容

万物 AI 仓库中，静态包位于 `public/office-characters/<id>/`，统一名单为 `shared/default-characters.mjs`。同时验证选择角色、桌面端编辑母版、成员头像和分身。新增名单不能覆盖任何成员当前形象。名称与介绍提供中英两版。

检查 64 / 96 / 160 px 与实际地图大小、浅/深底、正面待机、左右步态、五种工作、至少三轮持续庆祝、三个坐姿、困倦、快速切换、暂停、减少动态、两个独立实例。保留可操作预览；只把真实跑过的部分写成验证通过。

技能发布修改后递增 `bundled-skills/versions.json` 中对应版本，保留不可变旧版本；同步到 Codex 和 Claude 的技能目录，备份放在扫描目录外，避免备份也被注册成同名技能。不要修改其他技能的版本或已固定的版本选择。
