# 编辑已有角色：服装、配饰与局部造型

适用于“给橘子妹妹穿小裙子和蝴蝶结”“把香蕉叔叔的领带换成领结”“去掉帽子”“眼睛小一点”等连续编辑请求。直接修改现有角色包，交付同一个角色在页面里的更新，不只给建议或重新生成一只。

## 定位和保留

- 用当前选中角色、唯一名称或 id 定位实际实现。项目可能同时存在 SVG Web Component、Canvas 与旧五张 SVG；查看用户正在用的入口，不修改同名但未使用的实现。
- 先读当前母版、clips 和展示登记项。缺少具体颜色或配饰位置时按既有画风选取合适方案，不为普通可逆设计决定反复确认。
- 保留 id、名字、身体剪影、脸、配色逻辑、职业、已接受的动作池与接入路径，除非用户要求改变它们。不要为了穿裙子重新设计全身、统一体型或恢复招手/伸懒腰模板。
- 对即将替换的资源作可恢复备份；复用已有备份机制即可。不覆盖其他工具刚改过的无关内容。

## 服装与配饰

- 先明确挂接部位与遮挡：帽子、发饰跟头/叶子层，衣服跟 body，裙摆以腰部为锚点，手持道具与对应手部接触。这些层名是示意，以角色实际层级为准。
- SVG 优先在现有层级内新增语义组，例如 `data-accessory="bow"`、`data-accessory="dress"`。静态跟随父组即可；需要独立轻摆时增加唯一 `data-part` 和角色自己的 transform-origin。
- Canvas 角色在已有局部坐标系里绘制服装；其他引擎复用其实际骨骼/父子节点。不要给不同引擎套不适用的 SVG 分组。
- 新增配饰的原始坐标决定安装位置，动画外层只控制附加运动。避免 transform 覆盖定位导致配饰飞走；不要把帽子画在固定屏幕坐标上。
- 裙子应覆盖身体下部并留出脚步空间，不能把原有腿脚删掉；道具和手位于适当的前层。非对称配饰左右走时仍合理，不镜像文字。
- 服装用当前角色的平涂和描边语言，克制褶线与辅色。用户指定的新风格优先。和旧服饰占用同一位置时做必要搭配调整，并在交付中说明。
- 只为新增布料或配饰增加必要的轻微跟随动作，不因局部换装重做整套 clips。更新 design 的服装记录、相关颜色和描述，但不能把只改 metadata 当作已完成换装。

## 编辑表情与动作

“添加 emo 工作”“抓狂再夸张些”“完成独立出来”也进入编辑流程。读取 [情绪工作与独立完成状态](emotional-work.md)，修改真实五官与姿势、节奏、工作池或独立庆祝池；保留角色身份和服装。支持增删改变体，完成状态不得混入工作随机池。

## 验证

1. 校验母版、part 引用和 manifest；涉及网页或代码修改时执行项目构建。
2. 在实际入口查看正面、左右走、工作情绪、独立搞定了、犯困，以及原有随机待机；检查裙摆、蝴蝶结和手持物是否穿模、脱落、遮脸或被裁切。
3. 左右行走切回待机恢复正面；检查暂停与减少动态仍显示完整服装。小尺寸下衣服和脸保持可辨认。
4. 有浏览器工具时打开更新角色并留下可查看的预览；无法动态验证时明确说明。报告具体修改和保留项，不声称审美已经客观达标。

示例调用：
- Claude Code：`/office-character-studio 给橘子妹妹穿一条奶油色小裙子，戴豆沙色蝴蝶结，保留她原来的脸和随机小动作。`
- 当前项目快捷入口：`/edit-character 橘子妹妹 加一条小裙子和蝴蝶结。`
- Codex：`使用 $office-character-studio 给香蕉叔叔换上格子围巾，保留现有走路动作。`
