# 被整了 / Pranked

这是全员共有的第八个基础状态 `pranked`，用于轻松的卡通倒霉反应，不改变任务结果、真实账号或世界位置。原有库中的角色由新版宿主自动补上焦黑、呆住、白眼和小泪珠；无需批量重生成。源码 SVG、缓存 JSON 和其他状态保持原样。

新建角色要在 `states` 声明 `pranked` 并交付 `clips.pranked`。这是减少动态时的清晰基础姿态，`loop:true`，首尾一致，静态 SVG 中所有泪珠、烟、碎石等效果默认隐藏，只有对应 clip 显示。自定义 clip 优先于宿主默认焦黑效果，不要重复叠加。

创意由角色决定：可坐在地上哭、全身石化只剩眼睛动、眼镜滑落后呆住、头发炸开含泪、焦黑吐烟。保持身份、体型与脚底锚点；坐地哭属于表演，不占用真实座位。脸、姿势和配饰协调，在 96–137px 实际地图尺寸一眼能读懂。不要一律复制同一种哭脸，也不要用 tired 冒充。

可选 `prankedVariants:["pranked-cry", "pranked-stone"]`（最多 8 个）和 `prankedLabels`。每次进入状态由播放器随机选一个，变体均 `loop:true`，与 idle/work/done/sit/action 池完全分离。减少动态时保留静态基础 `pranked` 的首帧。切换状态取消全部旧动画、隐藏眼泪/烟/碎石，恢复母版颜色和关节。

手动菜单可选择「被整了 / Pranked」。道具规则使用 `emotion:"pranked"`；临时反应由服务端规定结束时间，结束恢复原有工作/站立/动作，不写入任务状态。定时或接触机关见场景技能的 `references/prop-behavior.md`。

验证旧包回退、新包自定义优先、多实例、快速切走、工作中暂时受击后恢复、深浅背景与减少动态。默认效果不是新增永久资产，也不自动给旧客户端注入能力；参与的客户端需升级后才能渲染该状态。

旧包迁移核验可使用 `--strict --allow-legacy-pranked`，仅放宽旧包缺少被整状态，其他严格检查保留；新创作只使用 `--strict`。
